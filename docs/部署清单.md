# 今日一行 — 微信云平台部署清单

> 前置条件：已在微信公众平台注册小程序，并开通云开发。

## 第一步：打开项目

在本地用**微信开发者工具**打开：

```
/home/c1/program/myProgram/今日一行/miniprogram
```

## 第二步：配置本地个人参数，不提交到 GitHub

### 2.1 配置 AppID

复制模板：

```bash
cp project.private.config.example.json project.private.config.json
```

然后在 `project.private.config.json` 中填写自己的小程序 AppID（如 `wx1234567890abcdef`）。

### 2.2 配置云环境 ID

复制模板：

```bash
cp env.example.js env.js
```

然后在 `env.js` 中填写云环境 ID（如 `prod-xxxxxx`）。

查看云环境 ID：微信开发者工具 → 云开发 → 设置 → 环境 ID

> `env.js` 和 `project.private.config.json` 是本地个人配置，已加入 `.gitignore`，不要提交到 GitHub。

## 第三步：创建数据库集合

### 3.1 cards 集合

1. 云开发控制台 → 数据库 → 新建集合 → 名称 `cards`
2. 导入数据 → 选择 `miniprogram/database/cards.seed.jsonl`
3. 设置权限：**所有用户可读，仅管理者可写**

### 3.2 checkins 集合

1. 新建集合 → 名称 `checkins`
2. 设置权限：**仅创建者可读写**
3. 添加索引：

| 索引字段 | 说明 |
|----------|------|
| `openid` 升序 + `date` 升序 | 用户每日打卡查询 |
| `card_id` 升序 | 卡片关联查询 |

## 第四步：上传云函数

### 4.1 上传 getTodayCard

在微信开发者工具中：
- 右键 `cloudfunctions/getTodayCard`
- 点击「上传并部署：云端安装依赖」

### 4.2 上传 toggleCheckin

- 右键 `cloudfunctions/toggleCheckin`
- 点击「上传并部署：云端安装依赖」

## 第五步：处理背景图

两种方式，任选其一：

### 方式 A：本地资源（推荐先试）

背景图已放在 `miniprogram/assets/backgrounds/` 下。  
直接编译即可，无需额外操作。

> ⚠️ 30 张图约 3.7MB，会增加小程序主包体积。如果超限可改用方式 B。

### 方式 B：云存储

1. 云开发 → 存储 → 上传 `miniprogram/assets/backgrounds/` 下 30 张图
2. 批量替换 `cards.seed.jsonl` 中 `background_url`，将：
   ```
   /assets/backgrounds/bg_01_hope_morning_path.jpg
   ```
   改为：
   ```
   cloud://prod-xxxxxx.7072.../backgrounds/bg_01_hope_morning_path.jpg
   ```
3. 可在 `scripts/` 下新建一个脚本做批量替换，或手动在云数据库中改

## 第六步：编译预览

1. 微信开发者工具点击「编译」
2. 确认首页卡片正常显示
3. 点击早/中/晚圆点，确认状态切换正常
4. 刷新页面，确认状态持久化

## 第七步：提交审核

1. 微信开发者工具 → 上传 → 填写版本号（如 `0.1.0`）
2. 微信公众平台 → 版本管理 → 选择刚上传的版本 → 提交审核
3. 审核通过后发布

## 常见问题

**Q: 打开空白页？**
- 检查 `env.js` 中云环境 ID 是否正确
- 检查 `getTodayCard` 云函数是否已部署
- 检查 `cards` 集合是否有数据（至少要有当天日期的一条）

**Q: 打卡不保存？**
- 检查 `checkins` 集合权限是否为「仅创建者可读写」
- 检查 `toggleCheckin` 云函数是否已部署

**Q: 背景图不显示？**
- 如果用本地路径，检查图片文件是否存在
- 如果用云存储，确认 fileID 格式正确（`cloud://env-id.xxx/path`）
