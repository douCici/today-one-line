# 今日一行：30 张背景图资源包

本包为微信小程序《今日一行》准备，包含 30 张 9:16 竖版背景图，适合“一张卡片 + 早中晚打卡”的极简首页。

## 内容

- `backgrounds/`：30 张 JPG 背景图，尺寸 1080×1920
- `backgrounds.json`：图片清单，可直接用于后台或 cards 表关联
- `backgrounds.csv`：表格版图片清单
- `docs/usage.md`：小程序使用说明
- `docs/license_note.md`：版权与来源说明
- `preview_contact_sheet.jpg`：30 张图的总览预览图

## 主题分组

- 希望 hope：5 张
- 平静 peace：5 张
- 感恩 gratitude：5 张
- 行动 action：5 张
- 信仰 faith：5 张
- 节制 restraint：5 张

## 设计原则

这些图不是从图库下载的照片，而是本次会话中用程序生成的极简抽象背景，避免人物、商标、建筑 logo、复杂摄影版权等问题。图片风格偏柔和、低对比、适合叠加半透明卡片和深色文字。

建议小程序第一版先使用这些背景图，后续如果要引入 Unsplash、Pexels、Pixabay 等图库素材，应单独保存原始链接、作者、授权条款和下载日期。
