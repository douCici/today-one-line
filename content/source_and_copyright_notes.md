# 来源与版权说明

## 1. 圣经内容

本包圣经类卡片主要依据中文和合本常见短句整理，并保留具体章节引用。公开资料中，eBible 的版权信息页把 Chinese Union Version (traditional) 列在 Public Domain Bibles 中；维基百科对 Chinese Union Version 的条目也标明其版权状态为 Public domain / copyright expired。

建议正式上线前确认你使用的中文译本版本。不要混用现代译本，例如现代中文译本、思高译本、新译本等，除非已获得授权。

## 2. 经典名著内容

本包经典类卡片优先采用中国古代典籍、公版经典文本，以及对公版西方经典的中文译写或思想概括。Project Gutenberg 的许可说明提醒，作品版权状态会因国家/地区不同而不同，若面向特定地区商业发布，应自行复核当地版权要求。

## 3. 名人/思想短句

本包名人/思想短句部分多采用“思想概括”方式，不强行把网络流传句子署名为某位名人，以降低误引和版权风险。Wikiquote 的版权说明也提醒，引用虽常因短小而可能落入合理使用范围，但不能把“短句”简单理解为完全无版权风险。

## 4. 正式上线建议

- 每条内容保留 `source_ref`。
- 不确定出处时，用“思想概括”或“人生格言”，不要强行署名。
- 现代作家、现代译本、现代诗歌、影视台词不建议直接使用。
- 小程序后台增加 `review_status` 和 `copyright_status` 字段。
- 上线前进行人工审核。
